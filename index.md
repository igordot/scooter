# scooter 🛴

Scooter is an R package that provides a streamlined framework for
loading, preprocessing, and plotting single-cell RNA-seq datasets. It
attempts to expedite routine analysis by providing data-agnostic methods
that work with multiple file/object formats with reasonable defaults.

The current `main` branch targets Seurat 5.

For older Seurat versions, see the
[seurat4](https://github.com/igordot/scooter/tree/seurat4) and
[seurat3](https://github.com/igordot/scooter/tree/seurat3) branches.
